# Свои текстуры

Положи сюда файл с нужным именем — игра сама подхватит его вместо
нарисованной заглушки, при следующей загрузке страницы. Размер картинки
любой (квадратной или нет) — впишется под тот же хитбокс автоматически.
Прозрачный PNG выглядит лучше всего.

| Файл                     | Что заменяет                                    |
|---------------------------|---------------------------------------------------|
| `character.png`           | персонаж (общий, если классового файла нет)       |
| `character_<класс>.png`   | **боевой спрайт** класса (fire/water/earth/air)    |
| `portrait_<класс>.png`    | **портрет в меню** для того же класса              |
| `icicle.png`               | сосульки Ледяного сердца                           |

**Почему два файла на класс.** В бою персонаж рисуется высотой ~36 px среди
десятков врагов: детальный портрет там превращается в тёмное пятно. Поэтому
`character_*` — уменьшенная и упрощённая версия с обводкой в цвет стихии (она
отделяет тёмную мантию от тёмного фона), а `portrait_*` — крупный арт как есть,
он показывается только в карусели выбора класса.

Оригиналы в полном разрешении лежат в `refs/`. Пересобрать оба файла из
оригинала можно скриптом `tools/make_sprites.py`.

Фон главного меню картинкой больше не задаётся — его рисует сцена (космос,
планета, чёрная дыра), см. `sky*` в `src/game.html`.

Классовый файл (`character_<класс>.png`) приоритетнее общего `character.png` —
если он есть, игра берёт именно его для этого класса, тинтом не красит.

Если файла нет — браузер тихо получит 404 в консоли и останется текущая
нарисованная заглушка, игра не ломается.

Чтобы добавить ещё один слот (например, отдельную текстуру для конкретного
снаряда или врага) — скажи, какой элемент, дальше это одна строчка в
`CUSTOM_ASSETS` в `index.html`.
