# Cursed &amp; Aura

Браузерная игра в духе Vampire Survivors / Magic Survival. Phaser 3 с CDN,
без своего бэкенда.

**Играть:** https://ism4il.github.io/cursed-aura/

Работает и на телефоне: управление — плавающий джойстик (касание в любом месте экрана),
кнопка паузы и кнопка полноэкранного режима в правом верхнем углу.

## Файлы

| Файл | Что это |
|---|---|
| `src/game.html` | **читаемый исходник** — HTML/CSS/движок игры. Содержит метки `/* @include data/x.js */` вместо больших таблиц контента |
| `src/data/weapons.js` | все заклинания, эволюции, слияния |
| `src/data/artifacts.js` | все артефакты (5 редкостей, caps) + благословения |
| `src/data/enemies.js` | категории врагов, кривые сложности по времени забега |
| `assemble.js` | разворачивает `@include`-метки — `src/game.html` + `src/data/*.js` → один текст. Им пользуются и `check.js`, и `build.js`, отдельно руками не запускается |
| `index.html` | публикуемый файл — генерируется из собранного исходника (`npm run build`), инлайн-скрипт минифицирован и обфусцирован. Не редактировать руками, перезатрётся при следующей сборке |
| `check.js` | проверки того, что ломается молча (`node check.js`) |
| `build.js` | сборка `index.html` (`npm run build`) |
| `assets/` | свои текстуры вместо нарисованных заглушек — см. `assets/README.md` |
| `serve.ps1` | локальный сервер для отладки (`powershell -File serve.ps1`, порт 8080) |

Правки: заклинание/эволюция/слияние → `src/data/weapons.js`. Артефакт/благословение →
`src/data/artifacts.js`. Враг/кривая сложности → `src/data/enemies.js`. Всё остальное
(движок, UI, телеметрия, HTML/CSS) → `src/game.html`. id у каждой записи — короткий
английский слаг (`warbrace`, `frostbite`...), не связан с отображаемым `name` — менять
русское название безопасно, ничего не сломается.

## Локально

```
powershell -File serve.ps1
```
и открыть http://localhost:8080/ (после `npm run build`, иначе отдаст старую сборку)

## Перед публикацией

```
npm install      # один раз
node check.js    # проверки по собранному исходнику
npm run build    # собрать index.html
```

`check.js` проверяет то, что не даёт о себе знать ни ошибкой, ни симптомом: совпадение
хитбоксов с текстурами, монотонность кривых сложности, наличие обработчика у каждого
типа заклинания, состав арены босса, привязку эффектов к игроку, систему артефактов.

Минификация — не настоящая защита кода (в DevTools всё ещё виден JS), но снимает
все комментарии-пояснения и перемешивает имена переменных, так что случайному
зрителю читать нечего.
