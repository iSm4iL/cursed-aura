# Cursed &amp; Aura

Браузерная игра в духе Vampire Survivors / Magic Survival. Один файл, без сборки:
`index.html` тянет Phaser 3 с CDN и содержит всю игру.

**Играть:** https://IKRIE.github.io/cursed-aura/ (ссылка заработает после включения GitHub Pages)

Работает и на телефоне: управление — плавающий джойстик (касание в любом месте экрана),
кнопка паузы и кнопка полноэкранного режима в правом верхнем углу.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся игра целиком |
| `check.js` | проверки того, что ломается молча (`node check.js`) |
| `serve.ps1` | локальный сервер для отладки (`powershell -File serve.ps1`, порт 8080) |

## Локально

```
powershell -File serve.ps1
```
и открыть http://localhost:8080/

## Проверки перед публикацией

```
node check.js
```

Проверяет то, что не даёт о себе знать ни ошибкой, ни симптомом: совпадение хитбоксов
с текстурами, монотонность кривых сложности, наличие обработчика у каждого типа
заклинания, состав арены босса, привязку эффектов к игроку.
